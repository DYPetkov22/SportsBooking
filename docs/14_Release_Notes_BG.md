# SportsBooking — промени в преработения ZIP (2026-11-04)

## Какво е променено

1. **Само Microsoft SQL Server:** премахнат SQLite NuGet пакет, SQLite connection strings и SQLite initialization. И Development, и Production използват SQL Server.
2. **SQL инсталация:** `database/01_SportsBooking_SQLServer.sql` създава шестте основни таблици, PK, FK, CHECK, UNIQUE, индекси и начални данни. В `database/03_Verify_SQLServer.sql` има заявки за проверка.
3. **Identity:** отделна SQL Server база `SportsBookingIdentityDB`, роли Admin/Manager/User; първоначалният администратор получава собствен бизнес профил.
4. **LINQ:** търсене/комбинирано филтриране/сортиране/пагинация в `Fields` и `Bookings`, без зареждане на всички записи в паметта. Клиентските резервации се ограничават по собственик преди заявките.
5. **По-пълен сайт:** Figma high-fidelity стилистика, sidebar, карти, dashboard, филтърни форми, статус индикатори, мобилно оформление, SVG лого и спортна илюстрация.
6. **Обновена документация:** README, SQL Server/Rider setup, ER диаграма, матрица на изискванията, 38 тестови сценария.
7. **Контрол на качеството:** `scripts/smoke_audit.py` със статични проверки и GitHub Actions build върху .NET 9.
8. **Версии:** EF Core SqlServer и Identity EFCore 9.0.22, ImageSharp 4.1.3.

## Какво трябва да се направи локално

- Инсталиране/стартиране на SQL Server (или LocalDB), изпълнение на SQL script, компилация на .NET 9 и реална проверка чрез браузър.
- Ако вече има SQLite база с реални данни — планиран export/import с проверки на потребителите и идентификаторите. **Не е извършено автоматично прехвърляне на данни.**
- Ако са нужни бъдещи промени в Identity схемата — добавяне и валидиране на EF Core migrations.

## Произход на дизайна

Архивът не съдържаше файлове `*.svg` от Figma. Използван е high-fidelity Figma проектът, посочен в `docs/03_Design_Brief.md`, като насока за структурата и цветовата схема. SVG графиките в `wwwroot/img/` са нови, включени като част от приложението.

- Статичните изисквания и структурата на проекта: **25/25 успешно**.
- XML валидност на трите SVG файла: успешно.
