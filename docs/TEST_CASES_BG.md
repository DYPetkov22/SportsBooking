# Ръчни тестове: .NET 9, Identity и права

**Предусловия:** изпълнен оригинален SQL скрипт, двете бази са достъпни, създаден Admin от environment variables, приложението е стартирано с HTTPS.

| № | Роля | Стъпки | Очакван резултат |
|---|---|---|---|
| 1 | Гост | Отвори `/Fields` | Вижда списъка, без бутони за редактиране/изтриване |
| 2 | Гост | Отвори `/Bookings` | Пренасочва към `/Account/Login` |
| 3 | Гост | Отвори `/Fields/Create` | Пренасочва към `/Account/Login` |
| 4 | Гост | Регистрирай нов имейл със сложна парола | Нов акаунт получава само роля `User` |
| 5 | Гост | Регистрирай имейл `ivan@example.com` от старите seed данни | Отказ: стар профил не може да бъде присвоен |
| 6 | Гост | Парола `abc123` | Валидация: прекалено слаба |
| 7 | Гост | Пет неуспешни влизания | Временно блокиране 10 минути |
| 8 | User | Отвори `/Roles` или `/Payments` | `403 / AccessDenied` |
| 9 | User | Създай собствена резервация | Успешно. `UserID` се присвоява от текущия акаунт |
| 10 | User | Изпрати POST Create с `UserID` на друг клиент | Игнорира се; записът пак е твой |
| 11 | User | Опитай GET `/Bookings/Details/{чужд ID}` | `403 / AccessDenied` |
| 12 | User | Опитай POST `/Bookings/Cancel/{чужд ID}` с antiforgery token | `403 / AccessDenied` |
| 13 | User | Опитай `/Bookings/Edit/{ID}` | `403 / AccessDenied` |
| 14 | User | Откажи свое активно резервиране | Статусът става `Отказана` |
| 15 | User | Резервирай вече зает час | Съобщение за конфликт; не се записва втори час |
| 16 | Admin | Отвори `/Roles`, избери Manager за друг регистриран потребител | Успешно и запазва роля |
| 17 | Manager | Влез отново, редактирай игрище | Разрешено |
| 18 | Manager | Опитай GET `/Users` и `/Roles` | Отказан достъп |
| 19 | Admin | Опитай да смениш своята роля през POST `/Roles/Update` | 400 BadRequest |
| 20 | User | Изход чрез POST `/Account/Logout`, после отвори `/Bookings` | Пренасочване към вход |
| 21 | User | POST без CSRF токен към `/Bookings/Cancel/{ID}` | HTTP 400 |
| 22 | Admin | Опитай да изтриеш профил `Users`, свързан с `AspNetUsers` | Изтриването е отказано |

**Бележка:** Таблицата описва тестове за изпълнение в локална среда. Не е отчетено реално изпълнение на тестовете.
