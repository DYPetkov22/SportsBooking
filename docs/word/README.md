# Word документация за предаване

Тази папка съдържа **осемте Word документа** от първото задание, плюс обединения файл `SportsBooking_Documentation_All.docx`. Те отразяват първоначалното проектиране на системата с 6 бизнес таблици.

**Важно:** следващият етап добавя MVC (.NET 9), Identity, потребителски роли и нови ограничения. За текущото изпълнение в GitHub използвай **актуализираните Markdown документи** в главната `docs/` папка и `docs/09_Security_Authentication.md`. Схемата на оригиналните шест бизнес таблици остава запазена.
